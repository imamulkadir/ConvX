# Filed-reference improvements

The user supplied a reference HTM and a ConvX HTM for CUSIP 06749LWD4 in a local CompareDocs folder, requested a gap analysis, then authorized adapting those gaps. This is post-refactor work; stages 1–10 remain complete and no Stage 11 is scheduled. Source documents are regression inputs, not issuer-specific conversion rules. The SEC-hosted original was not independently retrieved, so the supplied reference is a visual/structural target rather than a compliance whitelist.

## Changes

- Vertical marginal text is promoted to a header when the complete source page can accommodate it. The header starts at the source's top content margin when space permits. All horizontal content, tables, graphics and images move together. If the source cannot fit this arrangement, the existing deterministic vacant-band strategy remains. The printed-word verifier and each fresh ZIP audit independently derive the vertical note and body word positions from the actual PDF, retaining the existing 6pt displacement detector and raw source displacement measurements.
- Paragraphs now contain geometrically adjacent lines from the same source block/cell rather than one P per PDF line. Only permitted inline FONT elements occur inside P; there is no hidden duplicate text or invalid nested P/DIV. Actual source line geometry remains intact. Native PDF paragraph hints do not establish complete authorial semantics.
- Source tables and paragraphs share the existing recursive whitespace ordering algorithm, including multi-column separation. Tables no longer precede all surrounding text simply because the renderer constructs them first. Background graphics remain behind text. Native table cells retain their source positions and ownership.
- Conservative borderless field reconstruction requires at least three aligned colon-ended labels, paired value starts, a clear column gap and complete character ownership. It never wraps another table. Ambiguous or excessively complex field layouts stay as paragraphs rather than acquiring fabricated table structure.
- Ordinary HTTP SEC Archives links become HTTPS links to the identical host/path, with unchanged displayed source text. Existing URL validation still rejects foreign hosts, credentials, encoded traversal, queries and active schemes. The original strict and simple flow renderer defaults are unchanged.
- White pages are centered with gray side gutters through literal CSS2 horizontal auto margins, scoped to the separately hashed layered profile. Physical PDF page dimensions and print pagination remain unchanged. The reference's larger screen scale, CSS Grid, absolute positioning and calc() are not copied.
- Fully visible text avoids redundant clip boxes. Numeric CSS lengths retain six decimal places, far below browser geometry precision; source disclosure and font-family strings are never minified. Newly encoded JPGs use optimized entropy coding with unchanged quality/subsampling; original embedded JPEGs remain byte-exact. No asset is resized to imitate a particular logo.

The [CSS2 margin specification](https://www.w3.org/TR/CSS2/box.html#margin-properties) and [HTML4 paragraph content model](https://www.w3.org/TR/html4/struct/text.html#h-9.3.1) support the representation choices. The EFM78 STYLE interpretation remains local; neither these specifications nor resemblance to the supplied reference establishes SEC acceptance.
